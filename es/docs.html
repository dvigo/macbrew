Documentación y Guía de Uso de MacBrew

MacBrew es la herramienta definitiva para automatizar la configuración inicial de cualquier Mac nuevo o migración de equipo mediante Homebrew.

💡
¿Por qué usar MacBrew?

Evita descargar manualmente decenas de archivos .dmg o .pkg desde páginas web individuales. Con MacBrew, seleccionas lo que necesitas en una interfaz visual y obtienes un comando único o script ejecutable que instala todo automáticamente.

2. ¿Qué es Homebrew, Cask y Formula?

MacBrew genera instrucciones estandarizadas compatibles con Homebrew, el gestor de paquetes por excelencia para macOS.

Cask

Aplicaciones GUI

Son programas con interfaz gráfica de usuario tradicionales de macOS (ej. Google Chrome, Visual Studio Code, Slack, Spotify, Docker Desktop).

brew install --cask google-chrome
Formula

CLI Tools & Runtimes

Son librerías, entornos de programación y herramientas de línea de comandos (ej. Git, Node.js, Python, Go, ripgrep, jq).

brew install git node python

3. Guía de Uso Paso a Paso

1

Selecciona tus aplicaciones

Navega por las categorías del catálogo o utiliza el buscador para marcar las aplicaciones que deseas instalar. Si prefieres un perfil rápido, utiliza los Presets en la parte superior (ej. Full-Stack Dev, DevOps, Diseñador).

2

Revisa tu selección

En la barra inferior flotante verás en todo momento el número de herramientas elegidas. Haz clic en el botón "Obtener Instalador" para abrir el panel de exportación.

3

Elige tu formato de salida

Puedes optar por copiar un comando rápido de Terminal, descargar un Brewfile estándar o descargar el script interactivo install.sh.

4

Ejecuta en tu Terminal de Mac

Abre la aplicación Terminal en tu Mac (Cmd + Espacio > escribir "Terminal") y pega el comando o ejecuta el script descargado.

4. Formatos de Exportación Explicados

1. Comando de Terminal (One-Liner)

Ideal si ya tienes Homebrew instalado y deseas lanzar la instalación de inmediato:

brew install --cask google-chrome visual-studio-code slack && brew install git node

2. Brewfile (Homebrew Bundle)

El estándar oficial para infraestructura como código en macOS. Puedes guardar este archivo en tu repositorio de configuración de puntos dotfiles:

tap "homebrew/cask"

# Formulas
brew "git"
brew "node"

# Casks
cask "google-chrome"
cask "visual-studio-code"
cask "slack"

Para ejecutar un Brewfile, sitúate en la carpeta donde está guardado y ejecuta:

brew bundle

3. Script ejecutable install.sh

Script bash automatizado pensado para ordenadores nuevos. Incluye comprobación y auto-instalación de Homebrew si el sistema aún no lo tiene.

chmod +x install.sh
./install.sh

5. Opciones Avanzadas del Script

Al generar el script install.sh, puedes activar o desactivar las siguientes opciones:

Opción Flag / Comando Descripción
Auto-instalar Homebrew curl -fsSL .../install.sh Detecta si `brew` existe. Si no está, lo descarga e instala automáticamente configurando la variable `PATH` según la arquitectura de la Mac (Apple Silicon `arm64` o Intel `x86_64`).
Ignorar cuarentena --no-quarantine Evita la advertencia emergente de macOS Gatekeeper al abrir aplicaciones de origen seguro instaladas via Homebrew.
Limpieza final brew cleanup Elimina los archivos `.dmg` y `.tar.gz` temporales descargados en la caché para ahorrar espacio en disco.
Actualizar paquetes brew upgrade Actualiza todas las aplicaciones preexistentes a su última versión antes de instalar las nuevas.

6. Compartir Configuración en Equipo

MacBrew permite guardar y compartir listas de aplicaciones a través de la URL sin necesidad de crear cuenta ni guardar en base de datos.

🔗
Enlace Dinámico de Selección

Haz clic en el botón "Compartir" en la barra superior. Se copiará al portapapeles una URL con los parámetros codificados:

https://macbrew.app/?apps=visual-studio-code,docker,slack,git,node

7. Preguntas Frecuentes (FAQ)

¿MacBrew es gratis y de código abierto?

Sí, MacBrew es totalmente gratuito y abierto. No requiere registro ni suscripción.

¿Funciona en Mac con chip Apple Silicon (M1/M2/M3/M4)?

Sí, al 100%. Homebrew instala automáticamente versiones nativas de ARM64 para Apple Silicon y de x86_64 para procesadores Intel.

¿Qué ocurre si una aplicación ya está instalada?

Homebrew la detectará y mostrará una advertencia indicando que la aplicación ya existe, continuando con el resto del listado sin interrumpir la instalación.

¿Cómo desinstalar una aplicación instalada con Homebrew?

Solo debes abrir la Terminal y ejecutar brew uninstall --cask nombre-de-app (o brew uninstall nombre-de-formula).
